# НефтеПереработка — Django-приложение

Учебная автоматизированная система учёта нефтепереработки (АСУ НПЗ).
Стек: **Python 3.13 + Django 6.1 + SQLite**.

## Возможности

- ✅ **5 таблиц БД** (минимум требовался 2–3): НПЗ, марки сырой нефти,
  технологические установки, нефтепродукты, партии переработки.
- ✅ **Авторизация пользователей**: регистрация, вход/выход, админка.
  Создание и редактирование данных доступно только вошедшим пользователям.
- ✅ **Формы по нефтепереработке**: ModelForm для всех сущностей,
  валидация («объём продукта ≤ объём сырья») и калькулятор прогноза выхода продукта.
- Дашборд со статистикой, диаграммой объёмов по НПЗ и таблицей последних партий.
- Адаптивный тёмный интерфейс в промышленной стилистике.

## Запуск

```bash
# 1. Установить Django
py -m pip install django

# 2. Применить миграции и заполнить демоданными
py manage.py migrate
py manage.py seed

# 3. Создать суперпользователя (для /admin/)
py manage.py createsuperuser

# 4. Запустить сервер
py manage.py runserver
```

Откройте http://127.0.0.1:8000/

## Структура

```
refinery_project/   # настройки и URLs проекта
refining/           # приложение
  models.py         # 5 моделей (таблиц БД)
  forms.py          # формы, включая калькулятор выхода
  views.py          # дашборд, списки, детали, CRUD, регистрация
  urls.py           # маршруты
  admin.py          # админка
  management/commands/seed.py  # демоданные
  static/refining/style.css    # стили
templates/          # HTML-шаблоны (в т.ч. registration/)
db.sqlite3          # база данных SQLite
```

## Модели данных

| Модель | Назначение |
|--------|------------|
| `Refinery` | НПЗ: название, местоположение, мощность, год пуска |
| `CrudeOil` | Марка сырой нефти: плотность, сернистость, API |
| `ProcessUnit` | Установка НПЗ: тип процесса, мощность (FK → Refinery) |
| `Product` | Нефтепродукт: категория, плотность |
| `ProductionBatch` | Партия: сырьё → установка → продукт, объёмы и выход |

Связи: `ProductionBatch` ссылается на все остальные модели и на пользователя,
создавшего запись. Автоматически вычисляется процент выхода продукта.

> Примечание: в порту 8000 мог быть запущен другой проект. Если страницы не те,
> остановите чужой сервер или запустите приложение на другом порту,
> например `py manage.py runserver 8123`.
