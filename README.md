# НефтеПереработка — Django-приложение

Учебная автоматизированная система учёта нефтепереработки (АСУ НПЗ).
Стек: **Python 3.13 + Django 6.1 + SQLite**.

## Возможности

- **5 таблиц БД**: НПЗ, марки сырой нефти, технологические установки,
  нефтепродукты, партии переработки.
- **Авторизация пользователей**: регистрация, вход/выход, админка `/admin/`.
  Создание и редактирование данных доступно только вошедшим пользователям.
- **Формы**: `ModelForm` для всех сущностей, валидация
  («объём продукта не может превышать объём сырья»).
- Дашборд со сводной статистикой, таблицей последних партий
  и группировкой объёмов по НПЗ.
- Светлый интерфейс в промышленной стилистике (тёмно-синяя шапка, оранжевые акценты).

## Запуск

```bash
py -m pip install django
py manage.py migrate
py manage.py runserver
```

Откройте http://127.0.0.1:8000/

Если порт 8000 занят: `py manage.py runserver 8123`.

## Структура

```
refinery_project/   # настройки и URLs проекта
refining/           # приложение
  models.py         # 5 моделей (таблиц БД)
  forms.py          # формы и валидация
  views.py          # дашборд, списки, детали, CRUD, регистрация
  urls.py           # маршруты
  admin.py          # админка
  tests.py          # тесты
  management/commands/seed.py  # демоданные
  static/refining/style.css    # стили
templates/          # HTML-шаблоны (в т.ч. registration/)
db.sqlite3          # база данных SQLite (уже заполнена)
РАЗБОР_КОДА.md      # подробный разбор кода для начинающих
```

## Модели данных

| Модель | Назначение |
|--------|------------|
| `Refinery` | НПЗ: название, местоположение, мощность, год пуска |
| `CrudeOil` | Марка сырой нефти: плотность, сернистость, API |
| `ProcessUnit` | Установка НПЗ: тип процесса, мощность (FK → Refinery) |
| `Product` | Нефтепродукт: категория, плотность |
| `ProductionBatch` | Партия: сырьё → установка → продукт, объёмы и выход |

Процент выхода продукта вычисляется автоматически свойством `yield_percent`.

## Команды

```bash
py manage.py check             # проверить проект
py manage.py makemigrations    # подготовить изменение БД
py manage.py migrate           # применить миграции
py manage.py test refining     # запустить тесты
py manage.py seed              # пересоздать демоданные (внимание: очистит таблицы)
```
